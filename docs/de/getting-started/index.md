# Erste Schritte

Beginne hier, wenn du eine laufende Kamerplanter-Appliance willst und diese Module noch nicht genutzt hast.

- [Auf Proxmox VE bereitstellen](proxmox.md): vom leeren Proxmox-VE-Node bis zur Kamerplanter-Web-UI mit der fertigen Konfiguration in `src/scripts/proxmox`.

Anleitungen für weitere Anbieter folgen, sobald ihre Module existieren. Kleine eigene Hardware wie ein Mini-PC braucht keinen Infrastruktur-Code: Schreibe das Appliance-Image auf einen USB-Stick und starte davon, wie in der [Appliance-Dokumentation](https://github.com/nolte/kamerplanter-appliance) beschrieben.
